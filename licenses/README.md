# 외부 라이브러리·글꼴의 라이선스와 고지문

이 폴더에는 프로그램에 포함된 외부 라이브러리와 글꼴, 컬렉션 인식 자료를 만드는 데 사용한 글꼴의 라이선스와 고지문을 모았습니다.

아래 표에서 각 구성 요소의 버전과 라이선스 원문을 확인할 수 있습니다. DJMAXLocalRecords 자체 소스코드의 MIT 라이선스는 [LICENSE](https://github.com/Zionee148/DJMAXLocalRecords/blob/main/LICENSE)에, 게임 자료의 출처와 권리 표기는 [라이선스·출처](https://github.com/Zionee148/DJMAXLocalRecords/blob/main/guide/license.md)에 있습니다.
