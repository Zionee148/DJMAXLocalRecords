## 자료 출처

| 자료 | 출처 | 용도 |
| --- | --- | --- |
| 곡 정보 | [V-ARCHIVE OPEN API](https://v-archive.net/info/manual/api) | 곡 목록과 버튼·난이도별 패턴 정보를 표시합니다. |
| 숫자 표본·SCORE 모델 | 게임 화면에서 얻은 숫자 표본과 자체 학습한 모델 | 플레이 화면에서 SCORE를 찾아 읽습니다. |
| 동명곡 식별 자료 | 제작자가 직접 녹화한 게임 소리 | 소리에서 추출한 특징으로 같은 제목의 곡을 구분합니다. 원본 영상이나 음원 파일은 포함하지 않습니다. |
| 화면 글꼴 | SUIT, SUITE, Oxanium, Noto Sans JP | 프로그램과 OBS 오버레이의 글자를 표시합니다. |
| 컬렉션 인식 자료 | Lato, Noto Sans KR, Noto Sans JP로 그린 글자 그림, 게임 화면에서 얻은 숫자 표본과 카테고리 그림 | 게임 화면과 비교해 곡명·아티스트명과 점수를 읽습니다. Lato와 Noto Sans KR는 글자 그림만 배포합니다. |
