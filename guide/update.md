# 업데이트·복구

## 1. 프로그램에서 업데이트하기

**v1.1.0에서는 프로그램 안에서 v1.2.0으로 업데이트할 수 있습니다.** v1.0.0을 사용 중이면 다음 절의 **직접 업데이트하기**를 따릅니다.

1. 진행 중인 저장이나 가져오기를 마칩니다. 감지 중이면 **중지 / 숨기기**를 누르고, 열려 있는 기록 창과 설정 창을 닫습니다.
2. **업데이트 확인**을 눌러 새 버전과 패치노트를 확인합니다.
3. **업데이트**를 누르면 새 버전을 내려받고 현재 버전을 백업한 뒤 프로그램이 다시 실행됩니다. 파일 교체를 시작하기 전까지는 취소할 수 있습니다.

v1.2.0을 처음 실행하면 기존 기록과 설정을 실행 파일 옆 `UserData` 폴더로 복사합니다. 원본은 기존 위치에 남습니다.

## 2. 직접 업데이트하기

1. 프로그램을 종료하고 기존 프로그램 폴더 전체를 백업합니다.
2. [릴리즈 페이지](https://github.com/Zionee148/DJMAXLocalRecords/releases)의 **Assets**에서 이름이 `-win-x64.zip`으로 끝나는 파일을 내려받아 **새 폴더**에 압축을 풉니다.
3. 새 버전을 실행하기 전에, 기존 `DJMAXLocalRecords.exe` 옆에서 아래 항목을 찾아 **새 `DJMAXLocalRecords.exe` 옆에** 복사합니다. 목록에 있는 파일 중 실제로 있는 것만 복사하면 됩니다.

| 현재 사용 중인 버전 | 복사할 항목 |
| --- | --- |
| v1.2.0부터 | `UserData` 폴더 전체 |
| v1.1.0 | `records.json`, `records.json.bak`, `hotkeys.json`, `preferences.json`, `records-view.json`, `appearance.json` |
| v1.0.0 | `records.json`, `records.json.bak`, `hotkeys.json`, `preferences.json`, `records-view.json` |

새 폴더의 `DJMAXLocalRecords.exe`를 실행하고 프로필·최고 기록·설정을 확인합니다. v1.0.0 또는 v1.1.0에서 복사한 파일은 첫 실행 때 `UserData` 폴더로 자동 복사됩니다.

## 3. 이전 버전으로 복구하기

자동 업데이트는 직전 버전 하나를 백업합니다. 메인 창에서 **이전 버전 복구**를 누르고, 돌아갈 버전과 기록 위치를 확인한 뒤 **복구**를 누릅니다.

| 돌아가는 버전 | 복구 후 사용하는 기록 |
| --- | --- |
| v1.1.0 | 업데이트 전에 사용하던 실행 파일 옆의 기록과 설정을 사용합니다. v1.2.0에서 저장한 기록은 `UserData` 폴더에 남습니다. |
| `UserData`를 사용하는 버전 | 복구 후에도 같은 `UserData` 폴더의 기록과 설정을 사용합니다. |

**v1.1.0으로 복구했다가 다시 업데이트하면** `UserData`의 기록을 사용합니다. 복구 후 v1.1.0에서 저장한 판은 이 기록과 자동으로 합쳐지지 않습니다. 다만 v1.2.0에 옮기거나 저장한 기록이 없었다면, v1.1.0에서 처음 만든 기록을 가져옵니다.

### 프로그램이 열리지 않을 때

1. 프로그램을 완전히 종료한 뒤, 기존 설치 폴더에서 `update\backup`을 엽니다. 복구할 버전의 백업 폴더로 들어가 <strong>`program` 폴더 안의 `DJMAXLocalRecords.exe`</strong>를 실행합니다.
2. 복구 확인창에서 **복구**를 누릅니다(v1.1.0의 백업이면 **예**를 누릅니다). 복구가 끝난 뒤 프로그램이 자동으로 열리지 않으면 <strong>기존 설치 폴더의 `DJMAXLocalRecords.exe`</strong>를 실행합니다.
3. 백업의 실행 파일도 열리지 않으면 **`program` 안의 파일과 폴더만** 기존 설치 폴더에 복사해 덮어씁니다. `program` 옆의 `data`는 업데이트 전 개인 자료의 사본입니다. 현재 기록을 보존하려면 `data`는 그대로 둡니다.

사용할 수 있는 백업이 없으면 **직접 업데이트하기**의 순서에 따라 새 ZIP을 설치합니다.
