# 업데이트·복구

**v1.0.0을 사용 중이면 [‘직접 업데이트하기’](#2-직접-업데이트하기)를 따릅니다.** 자동 업데이트는 1.1.0부터 사용할 수 있습니다.

## 1. 자동 업데이트하기

프로그램을 시작할 때 새 **정식 버전**을 한 번 확인합니다. 실행 중에는 **업데이트 확인**을 눌러 직접 확인할 수 있습니다.

1. 진행 중인 저장·가져오기를 마치고, **중지 / 숨기기**로 감지를 중지합니다. 기록 목록과 설정 창도 닫습니다.
2. **업데이트 확인**을 눌러 새 버전과 패치노트를 확인합니다.
3. **업데이트**를 누르면 다운로드·파일 확인·백업을 거쳐 새 버전으로 다시 실행됩니다.

- 기록과 일반 설정은 유지됩니다. 오버레이 디자인은 새 버전과 호환되면 유지됩니다.
- 파일 교체가 시작되기 전까지 취소할 수 있습니다.
- 새 버전을 확인하지 못해도 현재 버전은 계속 사용할 수 있습니다.

파일 이름이 겹친다는 안내가 나오면 **안내에 나온 파일이나 폴더를 다른 곳으로 옮긴 뒤** 다시 시도합니다. 자동 업데이트를 사용할 수 없다는 안내가 나오면 아래 방법으로 직접 이전합니다.

## 2. 직접 업데이트하기

1. 프로그램을 종료하고 **기존 프로그램 폴더 전체를 백업**합니다.
2. [릴리즈 페이지](https://github.com/Zionee148/DJMAXLocalRecords/releases)에서 새 ZIP을 받아 **새 폴더에** 압축을 풉니다.
3. 기존 폴더에서 아래 파일을 새 폴더로 복사합니다. 없는 파일은 건너뜁니다.
4. 새 폴더의 `DJMAXLocalRecords.exe`를 실행하고 기록·설정이 유지되는지 확인합니다.

| 복사할 파일 | 내용 |
| --- | --- |
| `records.json` | 기록·프로필·되돌리기 이력 |
| `records.json.bak` | 기록의 직전 백업 |
| `hotkeys.json` | 단축키 설정 |
| `preferences.json` | 프로그램 설정 |
| `records-view.json` | 기록 목록 창 설정 |

**v1.0.0에서 처음 이전할 때는 `appearance.json`을 복사하지 않습니다.** 오버레이는 새 기본 디자인으로 시작합니다. 이후 수동 업데이트에서는 별도 안내가 없다면 이 파일도 복사해 디자인을 유지할 수 있습니다.

기존 실행 파일·DLL·`data` 폴더·`update-manifest.json`은 새 폴더에 덮어쓰지 않습니다.

## 3. 이전 버전으로 복구하기

자동 업데이트가 남긴 백업으로 **프로그램만 이전 버전으로 되돌립니다. 기록과 설정은 현재 내용을 유지합니다.**

### 프로그램이 실행되는 경우

**이전 버전 복구**를 누르고 되돌릴 버전을 확인한 뒤 승인합니다.

### 프로그램이 실행되지 않는 경우

1. 프로그램을 모두 종료합니다.
2. 프로그램 폴더에서 다음 순서로 들어갑니다.

   `update` → `backup` → 해당 버전 백업 폴더 → `program`

3. 그 안의 `DJMAXLocalRecords.exe`를 실행하고, 복구 여부를 묻는 창에서 **예**를 선택합니다.

### 백업의 실행 파일도 실행되지 않는 경우

프로그램을 모두 종료하고, 위의 **`program` 폴더 안에 있는 모든 파일과 폴더**를 원래 프로그램 폴더에 복사해 덮어쓴 뒤 다시 실행합니다.

**백업에서 `program`과 나란히 있는 `data` 폴더는 함께 복사하지 않습니다.** 그 안에는 업데이트 전 기록·설정의 사본이 있어 현재 기록을 덮어쓸 수 있습니다.

자동 백업은 **직전 버전 하나**만 유지됩니다. 다음 업데이트가 정상 완료되면 교체되므로, 오래 보관할 백업은 다른 곳에 복사합니다.
