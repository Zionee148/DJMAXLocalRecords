## SCORE 인식·등록

- 기록 등록을 RATE 인식에서 SCORE 직접 인식으로 변경하였습니다. 설정한 기어 위치에 맞게 SCORE 영역을 자동으로 찾고 추적합니다.
- 화면의 점수와 플레이 중 수집한 근거를 함께 확인하여 등록 후보를 제시하고, 사용자가 확인한 후 저장합니다.
- 근거가 부족하면 등록하지 않고, 실패 사유를 오버레이와 프로그램에 안내합니다.

## 기록 관리·저장

- 기록 목록에 세부 SCORE를 추가하고, 표시된 RATE가 같아도 SCORE가 더 높으면 최고 기록을 갱신하도록 개선하였습니다.
- 수동 기록 설정에서 SCORE와 RATE 입력이 서로 연동됩니다.
- 래더 연습모드의 하드 판정 기록이 노말 기록에 자동 반영되는 문제를 수정하였습니다.
- 저장·되돌리기 과정에서 기존 기록을 보호하는 기능을 강화하였습니다.

## 프로그램 UI·OBS 오버레이

- 메인 창과 세부 창 디자인을 개편하고, 라이트·다크 테마와 통일된 알림 창 디자인을 적용하였습니다.
- Windows 배율 125%·150%에서 글자가 잘리거나 겹치는 문제를 수정하였습니다.
- OBS 오버레이에 SCORE·RATE, 기존 기록과의 점수 차이, 짧은 인식 실패 사유를 표시하도록 개선하였습니다.

## 자동 업데이트

- 프로그램 실행 시 새 정식 버전을 확인하고, 사용자가 선택하면 업데이트하는 기능을 추가하였습니다.
- 직전 프로그램 버전 하나를 백업하며, 현재 기록과 설정을 유지한 채 이전 버전으로 복구할 수 있습니다.
- Windows x64용 배포 ZIP에 실행 환경을 포함하여 별도 .NET 설치 없이 실행할 수 있습니다.

## 최적화

- 프로그램 시작 시 불필요한 처리를 줄여 실행 대기 시간을 단축하고, RATE 숫자 판독의 이미지 처리를 최적화하였습니다.

## 오류 수정·진단

- Gregorius와 Cata의 Steam 곡명 표기 차이로 곡을 찾지 못하는 문제를 수정하였습니다.
- 현재 RATE 표시를 위한 숫자 판독과 위치 탐색을 보완하였습니다.
- 문제 해결을 위한 진단 기록 저장 기능을 추가하였습니다. 진단 기록과 그림은 외부로 자동 전송되지 않습니다.
