## SCORE 인식·등록

- 게임 화면에서 SCORE를 직접 읽도록 변경했습니다. 설정한 기어 위치에 맞춰 점수 영역을 찾고 추적합니다.
- 등록을 누르면 화면의 점수와 플레이 중에 읽은 값을 비교해 저장할 점수를 보여줍니다. 사용자가 확인하면 저장합니다.
- 점수를 확인할 수 없으면 오버레이와 메인 창에 이유를 표시합니다.

## 기록 관리·저장

- 기록 목록에 세부 SCORE를 추가했습니다. 표시된 RATE가 같아도 SCORE가 더 높으면 최고 기록을 갱신합니다.
- 수동 기록 설정에서는 SCORE와 RATE를 연동해 입력할 수 있습니다.
- 래더 연습모드의 하드 판정 기록이 노말 기록에 자동 반영되는 문제를 수정했습니다.
- 프로그램 실행 중 기록 파일이 외부에서 바뀌거나 사라지면 저장과 되돌리기를 중단하도록 했습니다.

## 프로그램 UI·OBS 오버레이

- 메인 창과 세부 창의 디자인을 바꾸고 라이트·다크 테마를 추가했습니다. 알림 창도 같은 디자인으로 통일했습니다.
- Windows 배율 125%·150%에서 글자가 잘리거나 겹치는 문제를 수정했습니다.
- OBS 오버레이는 등록을 확인할 때 SCORE와 RATE를 함께 보여줍니다. 저장 후에는 기존 기록이 있으면 점수 차이도 표시합니다. 인식에 실패하면 짧은 사유를 보여줍니다.

## 자동 업데이트

- 프로그램을 시작할 때 새 정식 버전을 확인합니다. 업데이트 여부는 직접 선택할 수 있습니다.
- 직전 버전 한 개를 백업합니다. 이전 버전으로 복구해도 현재 기록과 설정은 유지됩니다.
- Windows x64용 배포 ZIP에 실행 환경을 포함하여 별도 .NET 설치 없이 실행할 수 있습니다.

## 최적화

- 메인 창을 더 빨리 조작할 수 있도록 시작 시간을 줄였습니다. 현재 RATE를 읽을 때의 이미지 처리량도 줄였습니다.

## 오류 수정·진단

- Gregorius와 Cata의 Steam 곡명 표기 차이로 두 곡을 찾지 못하던 문제를 수정했습니다.
- 현재 RATE 표시를 위한 숫자 판독과 위치 탐색을 보완했습니다.
- 인식·등록 문제를 확인할 수 있도록 진단 기록을 추가했습니다. 진단 기록과 그림은 외부로 자동 전송되지 않습니다.

## 업데이트·제보 안내

- **v1.0.0에서는 수동으로 업데이트해야 합니다.** 새 ZIP을 새 폴더에 풀고 기록과 일반 설정을 옮겨 주세요. 오버레이는 새 기본 디자인으로 시작합니다.
- 인식·등록 오류가 발생하면 **진단 기록 폴더 열기**를 눌러 해당 폴더를 압축해 주세요. [GitHub Issues](https://github.com/Zionee148/DJMAXLocalRecords/issues)에 프로그램 버전, 발생 시각, 증상, 게임 해상도, 기어 이름과 위치를 적고, 압축한 진단 폴더를 첨부해 주세요. 첨부 파일은 공개되므로 올리기 전에 내용을 확인해 주세요.
